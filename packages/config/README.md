# @ayvo/config

Shared configuration only — no runtime code.

- `tsconfig/base.json` — strict base settings
- `tsconfig/node.json` — Node ESM (NodeNext) for `apps/api` and Node libraries
- `tsconfig/nextjs.json` — Next.js app
- `tsconfig/react-library.json` — React component packages
- `eslint/base` — shared ESLint flat config
