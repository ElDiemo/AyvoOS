# 015 — Data Dictionary

Tables of the AYVO OS PostgreSQL database (source of truth, ADR 0002). Schema:
`apps/api/prisma/schema.prisma`; migrations: `apps/api/prisma/migrations/`. Constraints marked
**(SQL)** are hand-written in the migration because Prisma cannot express them (ADR 0009).

Status: Milestone 1 (DEV only), 2026-10-10. Migrations: `20261010182950_bottles_labels_v0_1`,
`20261010200000_registration_idempotency_and_qr_host_check`.

Conventions: primary keys are UUIDv7 generated by PostgreSQL (`uuidv7()`), never shown publicly;
timestamps are `timestamptz(3)` in UTC; lengths in millimetres are `numeric(6,2)`.

> **Milestone 2A tables** (inventory, procurement, component attachments, operation requests)
> are documented in [018](018-inbound-stock-and-label-activation.md) §3–§4 and §15 and in the
> `DB:` comments of `apps/api/prisma/schema.prisma`.
>
> **Production Core v0.1 tables** (identity, catalog, crates, production, reservations, bottle
> category bindings, holds) are designed in [020](020-production-core-v0.1.md) §3 and not yet
> implemented; they are added here when their migrations exist.
>
> **Catalogue tables** (product categories, catalogue components, crate types, products, recipe
> versions, revisions and revision BOMs) are documented in
> [023](023-product-catalog-and-recipes.md) §3 and §6.

## Shared

### `code_counters`

Gapless counters for human-readable codes. Allocation: `UPDATE … SET last_value = last_value + n
RETURNING last_value` inside the business transaction (row lock until commit; rollback returns
the range). See [016](016-bottles-and-labels.md#numbering-and-concurrency).

| Column       | Type   | Notes                                                          |
| ------------ | ------ | -------------------------------------------------------------- |
| `name`       | text   | PK. Rows: `bottle`, `bottle_creation_batch`, `label_print_job` |
| `last_value` | bigint | Last allocated serial. CHECK ≥ 0 **(SQL)**                     |

SQL function `ayvo_format_code(prefix, serial)`: prefix + serial zero-padded to 6 digits (wider
above 999 999). Used by CHECK constraints on every code column.

SQL function `ayvo_url_host(url)`: lower-cased host of an absolute URL without userinfo, port or
trailing dot. Used by the QR environment CHECK on `label_print_jobs`.

Trigger `label_artworks_immutable`: rejects UPDATE/DELETE **(SQL)**.

### `label_templates`

| Column        | Type                  | Notes                                                                     |
| ------------- | --------------------- | ------------------------------------------------------------------------- |
| `id`          | uuid                  | PK                                                                        |

### `label_template_elements` — immutable

Positioned elements of a version. Origin top-left of the label, x right, y down, millimetres.

| Column                  | Type                    | Notes                                                                 |
| ----------------------- | ----------------------- | --------------------------------------------------------------------- |
| `id`                    | uuid                    | PK                                                                    |
| `version_id`            | uuid                    | FK → `label_template_versions`                                        |
| `type`                  | enum `LabelElementType` | v0.1: `QR_CODE`                                                       |
| `position`              | int                     | Drawing order; UNIQUE (`version_id`, `position`); CHECK ≥ 0 **(SQL)** |
| `x_mm`, `y_mm`          | numeric(6,2)            | Top-left corner of the box. CHECK ≥ 0 **(SQL)**                       |
| `width_mm`, `height_mm` | numeric(6,2)            | CHECK > 0; QR_CODE: width = height (square) **(SQL)**                 |
| `rotation_deg`          | int                     | CHECK = 0 in v0.1 **(SQL)**                                           |
| `properties`            | jsonb                   | Type-specific settings (future element types)                         |

Triggers: `label_template_elements_within_bounds` (box must lie on the label),
`label_template_elements_immutable` **(SQL)**. For QR_CODE the box includes the quiet zone.

## label-production module

### `label_print_jobs`

| Column                                                  | Type                          | Notes                                                         |
| ------------------------------------------------------- | ----------------------------- | ------------------------------------------------------------- |
| `id`                                                    | uuid                          | PK                                                            |
| `serial`, `code`                                        | bigint, text                  | Unique. `PJ-000001`; CHECK code/serial **(SQL)**              |
| `creation_batch_id`                                     | uuid                          | FK → `bottle_creation_batches`                                |
| `label_template_version_id`                             | uuid                          | FK → `label_template_versions` (rendered version)             |
| `label_count`                                           | int                           | CHECK 1–1000 **(SQL)**                                        |

| `app_environment`                                       | enum `AppEnvironment`         | `development` / `test` / `production` of the creating process |

| `status`                                                | enum `LabelPrintJobStatus`    | `PENDING`, `GENERATING`, `COMPLETED`, `FAILED`                |
| `attempts`                                              | int                           | Rendering attempts; CHECK ≥ 0 **(SQL)**                       |

Triggers: `label_print_jobs_identity_immutable` (id, serial, code, batch, version, label_count,
public_base_url, app_environment, qr_error_correction, created_at never change), `label_print_jobs_no_delete` **(SQL)**.
